## 4. Field diff v1 -> v2

### 4.1 Retained unchanged (name and intent)

`case_id`, `root_cause_label`, `primary_failure_layer`, `primary_failure_category`, `primary_failure_subtype`, `contributing_failure_1_layer`, `contributing_failure_1_category`, `contributing_failure_1_subtype`, `one_sentence_failure_summary`

**Vocabulary drift on retained taxonomy fields.** v1 used 4 layer values and 11 category values. The v2 prompt types these fields as free `string` without listing a vocabulary, so v2 realised 24 distinct layers and 57 distinct categories; 1147/1184 (96.9%) layers and 1110/1184 (93.8%) categories fall inside the v1 vocabulary; the rest are new coinages (e.g. `planning`, `execution`, `knowledge_gap`, `reasoning`). In v2 the controlled root-cause field is `trigger_mechanism` (9 values); the retained v1 taxonomy fields are carried for continuity only.
